# نظام قاعدة البيانات المحلية للتحليلات 🗄️

## 🎯 **ما هو هذا النظام؟**

نظام تحليلات محلي يسجل جميع أنشطة الزوار في ملفات JSON على الخادم، مما يعطيك بيانات حقيقية فوراً!

## 📊 **البيانات التي يتم تسجيلها:**

### 1. **بيانات الزوار** (`data/visitors.json`)
- معرف الزائر الفريد
- عنوان IP والموقع الجغرافي
- نوع المتصفح واللغة
- المصدر (من أين جاء)
- الثيم المفضل (ذهبي، أزرق، تراكوتا)

### 2. **الأنشطة** (`data/activities.json`)
- مشاهدة الصفحات
- مشاهدة المنتجات
- قراءة المقالات
- ملء النماذج
- البحث والتنزيلات

### 3. **موافقات الكوكيز** (`data/consents.json`)
- قبول/رفض كل نوع كوكيز
- وقت الموافقة
- إصدار سياسة الكوكيز
- تفاصيل المتصفح

## 🚀 **كيف يعمل النظام؟**

### **المرحلة 1: تتبع الزائر**
```javascript
// عند دخول زائر جديد
AnalyticsTracker.initializeVisitor({
  language: 'ar',
  theme: 'gold',
  country: 'Egypt'
});
```

### **المرحلة 2: تسجيل الأنشطة**
```javascript
// عند مشاهدة صفحة
AnalyticsTracker.trackPageView('/products/b123');

// عند مشاهدة منتج
AnalyticsTracker.trackProductView('b123_001', 'وسادة أنوبيس', 'b123');

// عند موافقة الكوكيز
AnalyticsTracker.trackCookieConsent({
  essential: true,
  analytics: true,
  marketing: false,
  preferences: true
});
```

### **المرحلة 3: عرض البيانات**
```javascript
// في لوحة التحكم
const stats = await fetch('/api/analytics/database?type=dashboard');
```

### **إحصائيات عامة:**
- إجمالي الزوار

### **أزرار التحكم:**
- 🗄️ **بيانات محلية**: من قاعدة البيانات المحلية

### **مؤشرات البيانات:**

## 🔧 **API Endpoints:**

### **تسجيل البيانات:**
```bash
# تسجيل زائر جديد
POST /api/analytics/track
{
  "type": "visitor",
  "data": { "sessionId": "...", "language": "ar" }
}

# تسجيل نشاط
POST /api/analytics/track
{
  "type": "activity", 
  "data": { "visitorId": "...", "activityType": "page_view" }
}

# تسجيل موافقة كوكيز
POST /api/analytics/track
{
  "type": "consent",
  "data": { "analytics": true, "marketing": false }
}
```

### **استرجاع البيانات:**
```bash
# إحصائيات عامة
GET /api/analytics/database?type=stats&days=7

# إحصائيات الكوكيز
GET /api/analytics/database?type=consent-stats

# لوحة التحكم الكاملة
GET /api/analytics/database?type=dashboard&days=30
```

## 🔒 **الأمان والخصوصية:**

### **حماية البيانات:**
- تشفير عناوين IP
- عدم حفظ معلومات شخصية
- تنظيف البيانات القديمة تلقائياً
- الامتثال لقوانين GDPR

### **إدارة البيانات:**
- حفظ آخر 30 يوم فقط
- حد أقصى 10,000 نشاط
- تنظيف تلقائي للبيانات القديمة

## 🎉 **المميزات:**

### ✅ **بيانات حقيقية فورية**
- لا تحتاج انتظار 24-48 ساعة
- تحديث فوري مع كل زائر
- إحصائيات دقيقة ومفصلة

### ✅ **سهولة الاستخدام**
- لا يحتاج إعداد معقد
- يعمل من أول زائر
- واجهة عربية جميلة

### ✅ **تحكم كامل**
- البيانات على خادمك
- لا تعتمد على خدمات خارجية
- تخصيص كامل للتقارير

### ✅ **متوافق مع GDPR**
- تسجيل موافقات الكوكيز
- احترام خصوصية المستخدمين
- شفافية في جمع البيانات

## 🚀 **كيفية الاستخدام:**

1. **شغل الموقع:** `npm run dev`
2. **ادخل الموقع:** `http://localhost:3000`
3. **اقبل الكوكيز** من البانر
4. **تصفح بعض الصفحات**
5. **اذهب للوحة التحكم:** `/admin/analytics`
6. **اضغط "🗄️ بيانات محلية"**
7. **شاهد البيانات الحقيقية!** 🎉
