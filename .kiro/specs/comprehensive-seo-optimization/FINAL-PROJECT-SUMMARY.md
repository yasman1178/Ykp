## ⚠️ Known Issues & Solutions

### Issue 1: Missing web-vitals Package

**Error**: `Cannot find module 'web-vitals'`

**Solution**:
```bash
npm install web-vitals
```

### Issue 2: ESLint Warnings

**Warnings**: Anonymous default exports, unescaped entities

**Solution**: These are minor warnings and don't affect functionality. Can be fixed later if needed.

### Issue 3: Image Optimization

**Warning**: Using `<img>` instead of Next.js `<Image>`

**Solution**: Replace `<img>` tags with Next.js `Image` component for better performance.
