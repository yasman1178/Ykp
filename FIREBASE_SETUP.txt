═══════════════════════════════════════════════════════════════
📋 الخطوات (10 دقائق فقط)
═══════════════════════════════════════════════════════════════

1️⃣ إنشاء مشروع Firebase
   ↓
   https://console.firebase.google.com/
   → اضغط "Add project"
   → اسم المشروع: pharaonic-pillows-analytics
   → اضغط "Create project"

2️⃣ إنشاء تطبيق ويب
   ↓
   → اضغط أيقونة Web </> 
   → اسم التطبيق: Pharaonic Pillows
   → اضغط "Register app"
   → انسخ firebaseConfig (ستحتاجه في الخطوة 4)

3️⃣ تفعيل Firestore
   ↓
   → من القائمة: Firestore Database
   → اضغط "Create database"
   → اختر "Start in production mode"
   → اختر الموقع: europe-west1 (أو الأقرب لك)
   → اضغط "Enable"
   
   → اذهب إلى تبويب "Rules"
   → الصق هذا الكود:
   
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /{document=**} {
         allow read, write: if true;
       }
     }
   }
   
   → اضغط "Publish"

4️⃣ إضافة المتغيرات في Vercel
   ↓
   → اذهب إلى: https://vercel.com/dashboard
   → اختر مشروعك
   → Settings → Environment Variables
   → أضف هذه المتغيرات (من firebaseConfig):

   NEXT_PUBLIC_FIREBASE_API_KEY=AIzaSyAnZne9Ah7Dr87o3-T1Xzs8E3fRVFuc6NE
   NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your-ykp-eg.firebaseapp.com
   NEXT_PUBLIC_FIREBASE_PROJECT_ID=ykp-eg
   NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=ykp-eg.firebasestorage.app
   NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=476269041962
   NEXT_PUBLIC_FIREBASE_APP_ID=1:476269041962:web:50462a28c0905544c4a653

 apiKey: "AIzaSyAnZne9Ah7Dr87o3-T1Xzs8E3fRVFuc6NE",
  authDomain: "ykp-eg.firebaseapp.com",
  projectId: "ykp-eg",
  storageBucket: "ykp-eg.firebasestorage.app",
  messagingSenderId: "476269041962",
  appId: "1:476269041962:web:50462a28c0905544c4a653",
  measurementId: "G-6WC940XZE4"
   → اضغط "Save" لكل متغير

5️⃣ إعادة النشر
   ↓
   git add .
   git commit -m "Add Firebase integration"
   git push

   (Vercel سيعيد النشر تلقائياً)

═══════════════════════════════════════════════════════════════
✅ التحقق من النجاح
═══════════════════════════════════════════════════════════════

1. افتح موقعك على Vercel
2. تصفح بعض الصفحات
3. اذهب إلى /admin/analytics
4. يجب أن ترى البيانات الحقيقية! 🎉

5. تحقق من Firebase:
   → افتح Firebase Console
   → Firestore Database
   → يجب أن ترى Collections جديدة:
     - visitors
     - daily_stats
     - product_analytics
